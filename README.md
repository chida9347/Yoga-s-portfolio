# Yoga's Portfolio

A personal portfolio website created to showcase profile information, skills, projects, education details, and contact information in a clean and responsive design.

## Features

- Responsive portfolio website
- Home section with introduction
- About section
- Skills section
- Projects showcase
- Contact section
- Simple and clean UI
- Easy navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
